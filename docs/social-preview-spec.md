# GitHub social preview

## Canvas

- **Recommended size:** 1280×640 px
- **Format:** PNG
- **Style:** dark, minimal, consistent with the application UI

## Layout

Use a two-column composition:

- **Left 35–40%:** FaceTrack Analytics logo, product name, and one short subtitle.
- **Right 60–65%:** cropped application hero screenshot with enough dashboard detail to read as a real desktop product.

Suggested text hierarchy:

1. **FaceTrack Analytics** — large product name
2. **Face tracking & unique-person analytics for Windows** — one restrained subtitle
3. Optional small line: **CUDA accelerated · English / Türkçe**

## Visual treatment

- Use the application’s near-black/navy background language.
- Keep one blue accent and one green status accent; avoid rainbow gradients.
- Give the screenshot a subtle border/radius treatment rather than a heavy mockup frame.
- Keep the logo small enough that the UI remains the main visual proof.

## Do not include

- benchmark percentages,
- long feature lists,
- excessive badges,
- “AI-powered” marketing text,
- flame/rocket imagery,
- YouTube-thumbnail typography,
- personal file paths or private test identifiers.

Before producing the final image, verify that the media visible inside the screenshot is cleared for public portfolio use.
